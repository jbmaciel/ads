Variáveis compostas homogêneas, índices e vetores de caracteres.
Situação-problema
Padronizar o CPF
Desafio da aula

Na instituição de ensino em que você trabalha, os CPFs são digitados no cadastro ora com pontos e traço, ora sem. Isso dificulta a indexação e a busca. Desenvolva um programa que padronize o CPF, eliminando os pontos e o traço digitados.

Um CPF é uma sequência de caracteres. Para examinar cada caractere, um por um, precisamos de uma estrutura que guarde vários valores em sequência: o vetor.

Motivação
15 variáveis ou uma só?
Sem vetor
float t1, t2, t3, t4, t5, t6, t7, t8, t9, t10, t11, t12, t13, t14, t15;
Com vetor
float t[15];

Criar uma variável para cada medição deixa o código longo e difícil de manter. A solução são as variáveis compostas: uma estrutura que reserva um grupo de blocos na memória, todos do mesmo tipo. Um int ocupa 4 bytes, então int t[15] reserva 15 blocos de 4 bytes.

Primitivas x Compostas
Uma casa ou um prédio?

Uma casa tem um endereço e um morador, como uma variável primitiva com um único valor. Um prédio tem um endereço com vários apartamentos, identificados por números. Nas variáveis compostas, esses "números de apartamento" são os índices.

Um vetor (ou array) é uma variável composta homogênea e unidimensional: uma tabela com uma única coluna e N linhas.

Inicialização e Utilização
Declarar, inicializar e acessar
<tipo> <nome_do_vetor>[tamanho];
1#include <stdio.h> 2int main(){ 3 int idade[3]; 4 float altura[3] = {1, 1.5, 1.7}; 5 idade[0] = 10; 6 idade[1] = 18; 7 idade[2] = 32; 8 printf("altura[0] = %.2f\n", altura[0]); 9 printf("altura[1] = %.2f\n", altura[1]); 10 printf("altura[2] = %.2f\n", altura[2]); 11 printf("idade[1] = %d\n", idade[1]); 12 return 0; 13}
Saída no terminal
altura[0] = 1.00 altura[1] = 1.50 altura[2] = 1.70 idade[1] = 18

Na linha 4, os valores iniciais ficam entre chaves, separados por vírgula. O material original imprimia o vetor float com %d, que é o código de inteiros e gera lixo. Para float, use %f.

Índices
A contagem começa no zero
1

Um vetor com N posições tem índices de 0 até N − 1.

2

O índice serve para ler e escrever: idade[0] = 10;

3

Com scanf, informe a posição: scanf("%d", &idade[1]);

C não verifica se o índice existe. Escrever em idade[3] num vetor de 3 posições invade a memória de outra variável: um erro silencioso e perigoso.

Vetores + Laços
O for percorre o vetor
1#include <stdio.h> 2int main(){ 3 float temp[5], soma = 0, media; 4 for (int i = 0; i < 5; i++) { 5 printf("Temperatura %d: ", i + 1); 6 scanf("%f", &temp[i]); 7 soma += temp[i]; 8 } 9 media = soma / 5; 10 printf("Media: %.2f\n", media); 11 printf("Acima da media:"); 12 for (int i = 0; i < 5; i++) { 13 if (temp[i] > media) 14 printf(" %.1f", temp[i]); 15 } 16 printf("\n"); 17 return 0; 18}
Saída no terminal
Temperatura 1: 22 Temperatura 2: 25.5 Temperatura 3: 19 Temperatura 4: 28 Temperatura 5: 24 Media: 23.70 Acima da media: 25.5 28.0 24.0

A variável do for vira o índice: com i indo de 0 a 4, temp[i] visita cada posição. O primeiro laço lê e acumula; o segundo usa os valores guardados para comparar com a média, o que seria impossível com uma única variável.

Características
O que todo vetor tem em comum
fix

Estrutura estática

O tamanho é definido na criação e não muda durante a execução. Nem todas as posições precisam ser usadas, mas todas ocupam memória.

???

Começa com lixo

O compilador só reserva o espaço. Sem inicialização, o vetor contém valores aleatórios deixados por outros programas.

[N]

Limites

Os índices válidos vão de 0 a N − 1. Acessar fora disso não gera erro de compilação, mas corrompe dados.

Vetores de Caracteres
Uma palavra é um vetor de char
char nome[16] = {'J', 'o', 'a', 'o'}; char sobrenome[31] = "Alberto Gomes"; char frase[101] = {"Disciplina de Algoritmos"};

A última posição útil é reservada para o \0, que marca o fim do texto. Por isso, nome[16] comporta 15 caracteres. As três formas de inicializar acima são equivalentes.

Lendo Strings
scanf para no espaço
1#include <stdio.h> 2int main(){ 3 char nome[31]; 4 printf("Nome completo: "); 5 scanf("%30s", nome); // sem &: nome ja e um endereco 6 printf("scanf leu: %s\n", nome); 7 return 0; 8}
Saída no terminal
Nome completo: Ana Maria Souza scanf leu: Ana
1#include <stdio.h> 2#include <string.h> 3int main(){ 4 char nome[31]; 5 printf("Nome completo: "); 6 fgets(nome, 31, stdin); 7 nome[strcspn(nome, "\n")] = '\0'; // tira o Enter 8 printf("fgets leu: %s\n", nome); 9 return 0; 10}
Saída no terminal
Nome completo: Ana Maria Souza fgets leu: Ana Maria Souza

Com %s, o scanf não usa &, porque o nome do vetor já é um endereço, e para no primeiro espaço. O fgets(destino, tamanho, stdin) lê a linha inteira, mas guarda também o Enter, removido com strcspn. O material sugeria fflush(stdin) antes do fgets, mas o padrão C não define fflush para entrada: em Linux e macOS, ele não faz nada.

Guarde o CPF digitado em um vetor de char.

2

Sugestão de Resolução
CPF padronizado com vetores
1#include <stdio.h> 2int main(){ 3 char cpf1[15]; // NNN.NNN.NNN-NN: 14 caracteres + '\0' 4 char cpf2[12]; // 11 digitos + '\0' 5 int n = 0; 6 printf("Digite seu CPF na forma NNN.NNN.NNN-NN: "); 7 scanf("%14s", cpf1); 8 for (int i = 0; cpf1[i] != '\0' && n < 11; i++) { 9 if (cpf1[i] == '.' || cpf1[i] == '-') { 10 continue; // ignora pontos e traco 11 } 12 cpf2[n] = cpf1[i]; // guarda apenas os digitos 13 n++; 14 } 15 cpf2[n] = '\0'; // fecha a string 16 printf("CPF sem formatacao = %s\n", cpf2); 17 return 0; 18}
Saída no terminal
Digite seu CPF na forma NNN.NNN.NNN-NN: 123.456.789-09 CPF sem formatacao = 12345678909

Digite seu CPF na forma NNN.NNN.NNN-NN: 98765432100 CPF sem formatacao = 98765432100

Matrizes
bidimensionais
Linhas e colunas, laços aninhados e operações com matrizes.
Situação-problema
Notas de vários alunos e disciplinas
Desafio da aula

A instituição quer um sistema de notas melhorado: armazenar as notas dos alunos em diferentes disciplinas, calcular a média de cada aluno e a média geral. Antes, esse controle era feito em uma tabela manual.

Os dados já têm forma de tabela: alunos nas linhas e disciplinas nas colunas. Qual estrutura de dados representa uma tabela?

Motivação
Uma tabela na memória
DiaMínimaMáxima
114º25º
212º24º
315º27º
417º29º
518º30º

As temperaturas de 5 dias formam uma estrutura com 5 linhas e 2 colunas. Poderíamos criar dois vetores, mas, assim como não queremos várias variáveis soltas, também não queremos vários vetores soltos.

Uma matriz é um conjunto de vetores, assim como um vetor é um conjunto de variáveis. Cada linha é um vetor de n valores, e a matriz é um vetor de m linhas: uma matriz m × n.

Inicialização e Utilização
Dois índices: linha e coluna
<tipo> <nome>[linhas][colunas];
Assim como nos vetores, os dois índices começam em zero: matriz[M][N] = valor; grava na linha M, coluna N.
int coordenadas[3][2]; float temperaturas[5][2]; int valores[3][2] = {{2, 3}, {5, 7}, {9, 11}};
Na inicialização, cada par de chaves internas é uma linha.
Exemplo de Matriz
Alunos nas linhas, bimestres nas colunas
1#include <stdio.h> 2int main(){ 3 float notas[3][2]; 4 notas[0][0] = 9.5; notas[0][1] = 10; // aluno 1 5 notas[1][0] = 4.5; notas[1][1] = 6.2; // aluno 2 6 notas[2][0] = 7; notas[2][1] = 8.5; // aluno 3 7 for (int i = 0; i < 3; i++) { 8 printf("Aluno %d:", i + 1); 9 for (int j = 0; j < 2; j++) 10 printf(" %5.1f", notas[i][j]); 11 printf("\n"); 12 } 13 return 0; 14}
Saída no terminal
Aluno 1: 9.5 10.0 Aluno 2: 4.5 6.2 Aluno 3: 7.0 8.5

notas[3][2] guarda 3 × 2 = 6 valores. Para um mesmo aluno, a linha fica fixa e a coluna muda. O material original tinha 8,5 com vírgula na nota do aluno 3, que em C não é um número decimal.

Matrizes + Laços Aninhados
Um for para linhas, outro para colunas
1#include <stdio.h> 2int main(){ 3 float notas[3][2]; 4 for (int i = 0; i < 3; i++) { // linhas: alunos 5 for (int j = 0; j < 2; j++) { // colunas: bimestres 6 printf("Nota %d do aluno %d: ", j + 1, i + 1); 7 scanf("%f", &notas[i][j]); 8 } 9 } 10 printf("Aluno 2, bimestre 1: %.1f\n", notas[1][0]); 11 return 0; 12}
Saída no terminal
Nota 1 do aluno 1: 8 Nota 2 do aluno 1: 7 Nota 1 do aluno 2: 6.5 Nota 2 do aluno 2: 9 Nota 1 do aluno 3: 10 Nota 2 do aluno 3: 5.5 Aluno 2, bimestre 1: 6.5

O for externo (i) escolhe a linha e o interno (j) percorre as colunas dessa linha. É o mesmo padrão da tabuada aninhada da Unidade 2, agora guardando os valores. No material original, faltava o ; no scanf da linha 7.

Operações com Matrizes
Somando as diagonais
1#include <stdio.h> 2int main(){ 3 int matriz[3][3]; 4 int i, j, sDiagPrinc = 0, sDiagSec = 0; 5 printf("Digite os elementos da matriz 3x3:\n"); 6 for (i = 0; i < 3; i++) 7 for (j = 0; j < 3; j++) 8 scanf("%d", &matriz[i][j]); 9 for (i = 0, j = 2; i < 3 && j >= 0; i++, j--) { 10 sDiagPrinc += matriz[i][i]; // linha = coluna 11 sDiagSec += matriz[i][j]; // coluna anda ao contrario 12 } 13 printf("Diagonal principal: %d\n", sDiagPrinc); 14 printf("Diagonal secundaria: %d\n", sDiagSec); 15 return 0; 16}
Saída no terminal
Digite os elementos da matriz 3x3: 2 0 1 3 5 7 4 6 8 Diagonal principal: 15 Diagonal secundaria: 10

Na principal, linha e coluna são iguais: matriz[i][i]. Na secundária, enquanto i sobe, j desce: duas variáveis no mesmo for. O original usava i < 3, j >= 0. Como vimos na Unidade 2, a vírgula descarta o primeiro teste: use &&.

Operações com Matrizes
Linha vezes coluna
C[i][j] = Σ A[i][k] × B[k][j]
Lê-se: "o elemento da linha i e coluna j de C é a soma dos produtos da linha i de A pela coluna j de B".

Só é possível multiplicar se o número de colunas de A for igual ao número de linhas de B. Uma matriz m × n vezes uma n × q gera uma matriz m × q.

Operações com Matrizes
Três laços aninhados
1#include <stdio.h> 2int main() { 3 int m, n, p, q, i, j, k; 4 printf("Dimensoes da 1a matriz (m n): "); 5 scanf("%d %d", &m, &n); 6 printf("Dimensoes da 2a matriz (p q): "); 7 scanf("%d %d", &p, &q); 8 if (n != p) { // colunas da 1a = linhas da 2a? 9 printf("Multiplicacao impossivel.\n"); 10 return 0; 11 } 12 int A[m][n], B[p][q], C[m][q]; 13 printf("Elementos da 1a matriz:\n"); 14 for (i = 0; i < m; i++) 15 for (j = 0; j < n; j++) 16 scanf("%d", &A[i][j]); 17 printf("Elementos da 2a matriz:\n"); 18 for (i = 0; i < p; i++) 19 for (j = 0; j < q; j++) 20 scanf("%d", &B[i][j]); 21 for (i = 0; i < m; i++) 22 for (j = 0; j < q; j++) { 23 C[i][j] = 0; 24 for (k = 0; k < n; k++) 25 C[i][j] += A[i][k] * B[k][j]; 26 } 27 printf("Produto:\n"); 28 for (i = 0; i < m; i++) { 29 for (j = 0; j < q; j++) 30 printf("%d\t", C[i][j]); 31 printf("\n"); 32 } 33 return 0; 34}
Saída no terminal
Dimensoes da 1a matriz (m n): 2 3 Dimensoes da 2a matriz (p q): 3 2 Elementos da 1a matriz: 1 2 3 4 5 6 Elementos da 2a matriz: 7 8 9 10 11 12 Produto: 58 64 139 154
Saída: dimensões incompatíveis
Dimensoes da 1a matriz (m n): 2 3 Dimensoes da 2a matriz (p q): 2 2 Multiplicacao impossivel.

A linha 12 declara as matrizes com tamanhos lidos do usuário (arrays de tamanho variável, do padrão C99). O terceiro for (k) faz a soma dos produtos. Zerar C[i][j] antes da soma evita somar lixo.

Sugestão de Resolução
A diretiva #define
#def

Constantes simbólicas

#define NUM_ALUNOS 3 dá um nome ao valor 3. Antes da compilação, o pré-processador troca cada NUM_ALUNOS por 3. Para atender 40 alunos, basta mudar uma linha.

fix

Diferenças para o material

O original declarava duas variáveis soma (uma escondendo a outra), seus comentários falavam em média "em cada disciplina" sem calculá-la, e a média geral era a média das médias. Aqui a média de cada disciplina também é calculada.

Com o mesmo número de disciplinas por aluno, a média das médias é igual à média de todas as notas: 70 ÷ 9 = 7,78.

Structs:
registros
Estruturas heterogêneas, operador ponto, vetores de structs e typedef.
Situação-problema
Gestão da biblioteca
Desafio da aula

A biblioteca da instituição precisa de um sistema que armazene, para cada livro, título, autor, ISBN, ano de publicação e quantidade em estoque. O sistema deve buscar livros por autor, verificar a disponibilidade e atualizar o estoque.

Título é texto, ano é inteiro, estoque é inteiro… Vetores e matrizes só guardam um tipo. Como manter todos os dados de um livro juntos?

Definição
Um formulário de cadastro
struct <nome> { <tipo> <nome_da_variavel1>; <tipo> <nome_da_variavel2>; ... };
struct Cadastro { char cpf[12]; char nome[30]; int idade; char rua[50]; int numero; };

Uma struct (ou registro) é uma estrutura composta heterogênea: agrupa campos de tipos diferentes, como os campos de um formulário. Ela é definida antes do main() e funciona como um novo tipo de dado.

Os nomes dos campos (membros) precisam ser únicos dentro da struct, mas structs diferentes podem repetir nomes. O cpf tem 12 posições: 11 dígitos + \0. No material, ele tinha 11.

Variáveis do Tipo Struct
O tipo existe. Agora, as variáveis
Depois da definição
struct Cadastro cliente1;
A palavra struct é obrigatória antes do nome do tipo. cliente1 tem dentro dela todos os campos: cpf, nome, idade, rua e numero.
Junto com a definição
struct Cadastro { char cpf[12]; char nome[30]; ... } cliente1, cliente2;
As variáveis vêm depois da chave de fechamento e antes do ponto e vírgula.
Manipulação de Dados
O operador ponto
1#include <stdio.h> 2#include <string.h> 3struct Aluno { 4 int numMat; 5 char nome[30]; 6 char sexo; 7 int idade; 8}; 9int main(){ 10 struct Aluno aluno1; 11 aluno1.numMat = 1000; 12 strcpy(aluno1.nome, "Joao"); // copia o texto para o campo 13 aluno1.sexo = 'M'; 14 aluno1.idade = 19; 15 struct Aluno aluno2 = {2000, "Maria", 'F', 18}; 16 printf("%d | %s | %c | %d\n", aluno1.numMat, aluno1.nome, 17 aluno1.sexo, aluno1.idade); 18 printf("%d | %s | %c | %d\n", aluno2.numMat, aluno2.nome, 19 aluno2.sexo, aluno2.idade); 20 return 0; 21}
Saída no terminal
1000 | Joao | M | 19 2000 | Maria | F | 18
.

variavel.campo

aluno1.idade = 19; acessa o campo idade da variável aluno1.

str

strcpy

Strings não aceitam = depois da declaração. strcpy (de string.h) copia "Joao" para aluno1.nome.

{ }

Inicialização

Os valores entre chaves seguem a ordem dos campos. Campos omitidos, como em {2000, "Maria"}, recebem 0 ou texto vazio.

Entrada de Dados
Cada campo, com seu código
scanf("%d", &aluno1.numMat); // inteiro: precisa de & scanf("%29s", aluno1.nome); // string: sem & fgets(aluno1.nome, 30, stdin); // ou a linha inteira

Cada campo é lido como uma variável comum, respeitando seu tipo: %d para int, %s ou fgets para strings, %c para char. No material, o exemplo com fgets usava o campo errado: fgets(aluno1.numMat, ...) tenta gravar texto em um inteiro. O correto é aluno1.nome.

Structs em Algoritmos
Um vetor de registros
1#include <stdio.h> 2typedef struct { 3 char nome[20]; 4 int idade; 5} Aluno; 6int main(){ 7 Aluno alunos[3]; 8 int maisVelho = 0; 9 for (int i = 0; i < 3; i++) { 10 printf("Nome e idade do aluno %d: ", i + 1); 11 scanf("%19s %d", alunos[i].nome, &alunos[i].idade); 12 if (alunos[i].idade > alunos[maisVelho].idade) 13 maisVelho = i; 14 } 15 printf("Mais velho: %s (%d anos)\n", 16 alunos[maisVelho].nome, alunos[maisVelho].idade); 17 return 0; 18}
Saída no terminal
Nome e idade do aluno 1: Ana 19 Nome e idade do aluno 2: Bruno 23 Nome e idade do aluno 3: Carla 21 Mais velho: Bruno (23 anos)
ExpressãoSignificado
alunos[1]o 2º registro inteiro
alunos[1].idadeo campo idade do 2º registro
alunos[i].nomeo nome do registro i

O índice vem antes do ponto: primeiro escolhemos o registro, depois o campo.

Apelidos para Tipos
typedef: menos digitação
Sem typedef
struct Aluno { char nome[20]; int idade; }; struct Aluno aluno1;
Com typedef
typedef struct { char nome[20]; int idade; } Aluno; Aluno aluno1;

typedef <tipo existente> <novo nome>; cria um apelido para um tipo. Não surge um tipo novo: é só uma simplificação que dispensa a palavra struct na declaração.

Declaração, operadores * e &, NULL, aritmética e ponteiros para estruturas.
Situação-problema
O desafio do +10
Desafio da aula

Em um evento de tecnologia, um grupo de alunos pediu ajuda com um exercício: declarar um vetor de inteiros e um ponteiro para inteiros, associar o ponteiro ao vetor e somar 10 a cada posição usando aritmética de ponteiros.

Para ajudá-los, você precisa entender o que é um ponteiro e como ele "anda" pela memória.

Conceitos Básicos
Uma variável que guarda um endereço
<tipo> *<nome_do_ponteiro>;
int ano = 2018; int *ponteiro_para_ano = &ano;
Lê-se: "ponteiro_para_ano recebe o endereço de ano". Nos exemplos a seguir, vamos chamá-lo simplesmente de p.
*Na declaração: indica que a variável é um ponteiro. No uso: acessa o valor apontado
&Operador de referência: devolve o endereço de uma variável

Um ponteiro armazena exclusivamente endereços de memória. O tipo (int *) diz para que tipo de dado ele aponta. Ponteiros são a base da alocação dinâmica de memória e das estruturas de dados mais avançadas.

Representação
Quem aponta para quem
1#include <stdio.h> 2int main(){ 3 int ano = 2018; 4 int *p = &ano; // p guarda o endereco de ano 5 printf("ano = %d\n", ano); 6 printf("p = %p\n", (void *) p); // endereco de ano 7 printf("*p = %d\n", *p); // valor apontado 8 printf("&p = %p\n", (void *) &p); // endereco do proprio p 9 *p = 2026; // altera ano pelo ponteiro 10 printf("ano = %d\n", ano); 11 return 0; 12}
Saída no terminal
ano = 2018 p = 0x7fffb7ab308c *p = 2018 &p = 0x7fffb7ab3090 ano = 2026

O ponteiro também ocupa memória e tem seu próprio endereço. Os endereços reais mudam a cada execução. Ao contrário do que diz o material, o conteúdo do ponteiro não muda quando ano muda: ele continua guardando o mesmo endereço, e é *ponteiro que reflete o novo valor.

p, *p e &p

O material sugere %x como alternativa para endereços, mas em sistemas de 64 bits o endereço não cabe em um unsigned int. Use %p, de preferência convertendo para (void *).

Ponteiro Nulo

Indica explicitamente que o ponteiro não aponta para nenhum endereço válido.

✓

Verificar se o ponteiro é NULL antes de acessar *ponteiro evita erros de acesso à memória.

→

Operações com Ponteiros
Andando pela memória
1#include <stdio.h> 2int main(){ 3 int numeros[5] = {10, 20, 30, 40, 50}; 4 int *p = &numeros[0]; // o mesmo que: p = numeros; 5 int *q = &numeros[4]; 6 printf("*p = %d\n", *p); 7 printf("*(p + 2) = %d\n", *(p + 2)); 8 p++; // avanca para numeros[1] 9 printf("apos p++, *p = %d\n", *p); 10 (*p)++; // incrementa o CONTEUDO 11 printf("apos (*p)++, numeros[1] = %d\n", numeros[1]); 12 if (p < q) 13 printf("p aponta antes de q\n"); 14 printf("q - p = %td posicoes\n", q - p); 15 return 0; 16}
Saída no terminal
*p = 10 *(p + 2) = 30 apos p++, *p = 20 apos (*p)++, numeros[1] = 21 p aponta antes de q q - p = 3 posicoes
p++ / p--avança ou volta um elemento
*(p + 2)valor dois elementos à frente

Com ponteiros, só valem adição e subtração de inteiros. p + 1 avança um elemento, e não um byte: com int, são 4 bytes. Comparar com < ou > só faz sentido entre ponteiros do mesmo vetor.

Ponteiros para Estruturas
O operador seta (->)
1#include <stdio.h> 2struct aluno { 3 int mat; 4 float nota; 5}; 6int main(){ 7 struct aluno joao; 8 struct aluno *ptr; // ponteiro para struct 9 joao.mat = 1000; 10 joao.nota = 8.5; 11 ptr = &joao; 12 printf("Matricula: %d\n", ptr->mat); 13 printf("Nota: %.1f\n", ptr->nota); 14 ptr->nota = 9.0; // altera joao pelo ponteiro 15 printf("joao.nota agora: %.1f\n", joao.nota); 16 return 0; 17}
Saída no terminal
Matricula: 1000 Nota: 8.5 joao.nota agora: 9.0

Com um ponteiro para struct, acessamos os campos com ->. A expressão ptr->mat é uma forma curta de escrever (*ptr).mat. Alterar ptr->nota altera a própria variável joao.

Ponteiros para Vetores
O nome do vetor é um endereço
1#include <stdio.h> 2int main(){ 3 char vet[5] = {'a', 'b', 'c', 'd', 'e'}; 4 char *ptr = vet; // vet ja e o endereco de vet[0] 5 for (int i = 0; i < 5; i++) { 6 printf("vet[%d] = %c | *ptr = %c\n", i, vet[i], *ptr); 7 ptr++; // proximo elemento 8 } 9 return 0; 10}
Saída no terminal
vet[0] = a | *ptr = a vet[1] = b | *ptr = b vet[2] = c | *ptr = c vet[3] = d | *ptr = d vet[4] = e | *ptr = e

ptr = vet; funciona sem &, porque vet já é o endereço de vet[0]. O printf do material original não fechava as aspas.

Matrizes e Ponteiros
Linhas, uma após a outra

Mesmo tendo duas dimensões, a matriz é guardada linearmente na memória: toda a linha 0, depois toda a linha 1, e assim por diante. Por isso, um ponteiro pode percorrer uma matriz como se fosse um vetor: o elemento m[i][j] fica na posição i × colunas + j.

Atividade
Somar 10 com aritmética de ponteiros
Desafio

Escreva um programa que declare um vetor de 5 inteiros e um ponteiro para inteiros. Associe o ponteiro ao vetor e some +10 a cada posição usando aritmética de ponteiros. Por fim, mostre o vetor.

Lembre-se: se p aponta para vetor[0], então *(p + i) é o mesmo que vetor[i].

Sugestão de Resolução
+10 com ponteiros
1#include <stdio.h> 2int main() { 3 int vetor[5] = {1, 2, 3, 4, 5}; 4 int *ponteiro = vetor; // associa o ponteiro ao vetor 5 for (int i = 0; i < 5; i++) { 6 *(ponteiro + i) += 10; 7 } 8 printf("Vetor apos somar 10:\n"); 9 for (int i = 0; i < 5; i++) { 10 printf("%d ", vetor[i]); 11 } 12 printf("\n"); 13 return 0; 14}
Saída no terminal
Vetor apos somar 10: 11 12 13 14 15
Outra forma: o ponteiro anda
for (int *p = vetor; p < vetor + 5; p++) *p += 10;

As alterações feitas por *(ponteiro + i) aparecem ao imprimir vetor[i], porque os dois nomes acessam a mesma memória.
