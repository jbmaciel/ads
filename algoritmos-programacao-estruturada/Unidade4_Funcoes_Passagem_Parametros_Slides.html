Desafio da aula

Um laboratório de pesquisa precisa ajudar engenheiros civis a escolher o guindaste que vai erguer colunas de concreto. O peso da coluna é P = V × R, em que V é o volume e R = 25 kN/m³. A partir da base, largura e altura da coluna, o programa deve informar o guindaste.

500 kg < Peso ≤ 1500 kgG2

Problemas grandes, partes pequenas
♻

Reutilização

Em vez de repetir comandos, chamamos a função quantas vezes precisarmos.

✎

Manutenção

Um ajuste na tarefa é feito em um único lugar.

🔍

Clareza

Cada função tem uma tarefa específica: o código fica legível e os erros, fáceis de achar.

Sintaxe de Funções
As partes de uma função
<tipo de retorno> <nome>(<parâmetros>) { <comandos da função> return <valor>; // se não for void }
tipoObrigatório. int, float, char… ou void, quando nada é devolvido (procedimento)
nomeObrigatório. Mesmas regras de nomes de variáveis: sem acentos, espaços ou símbolos
( )Obrigatórios, mesmo sem parâmetros
parâmetrosOpcionais. Valores que a função recebe para trabalhar
returnDevolve um único valor e encerra a função imediatamente
Como na Matemática
f(3) = 3 + 2 = 5
f(x) = x + 2 → f(3) = 5
O 3 substitui o x: é o parâmetro com que a função faz o cálculo. Em C, os valores da chamada ocupam os parâmetros na mesma ordem.

Ao encontrar somar(4, 5), a execução salta para a função, x recebe 4 e y recebe 5. O return devolve o resultado para o ponto da chamada, onde ele é guardado em resultado.

Função com Parâmetros
Definir uma vez, chamar várias
1#include <stdio.h> 2int somar(int x, int y){ 3 int s = x + y; 4 return s; 5} 6int main(){ 7 int resultado = somar(4, 5); 8 printf("somar(4, 5) = %d\n", resultado); 9 printf("somar(10, -3) = %d\n", somar(10, -3)); 10 return 0; 11}
Saída no terminal
somar(4, 5) = 9 somar(10, -3) = 7

A função é definida antes do main(), para que o compilador a conheça quando ela for chamada. O resultado pode ser guardado em uma variável (linha 7) ou usado direto em outra expressão (linha 9). No material original, o exemplo com parâmetros não tinha o #include <stdio.h>.

void
Procedimento: faz, mas não devolve
1#include <stdio.h> 2void linha(int n){ // void: nao devolve valor 3 for (int i = 0; i < n; i++) 4 printf("-"); 5 printf("\n"); 6} 7int main(){ 8 linha(24); 9 printf(" Boletim do aluno\n"); 10 linha(24); 11 printf(" Media final: 8.5\n"); 12 linha(24); 13 return 0; 14}
Saída no terminal
------------------------ Boletim do aluno ------------------------ Media final: 8.5 ------------------------

Uma função com tipo de retorno void é chamada de procedimento: executa uma tarefa, como desenhar a linha, mas não devolve valor. Por isso não precisa de return, e sua chamada aparece sozinha, como um comando.

Funções e Ponteiros
Devolvendo um vetor
1#include <stdio.h> 2#include <stdlib.h> 3int* gerarRandomico(){ 4 static int r[5]; // static: o vetor sobrevive ao fim da funcao 5 for (int a = 0; a < 5; a++) { 6 r[a] = rand() % 100; // valores de 0 a 99 7 printf("r[%d] = %d\n", a, r[a]); 8 } 9 return r; // devolve o endereco de r[0] 10} 11int main(){ 12 int *p = gerarRandomico(); 13 for (int i = 0; i < 5; i++) 14 printf("p[%d] = %d\n", i, *(p + i)); 15 return 0; 16}
Saída no terminal
r[0] = 83 r[1] = 86 r[2] = 77 r[3] = 15 r[4] = 93 p[0] = 83 p[1] = 86 p[2] = 77 p[3] = 15 p[4] = 93

Não existe int[5] f(): a função devolve int*, o endereço do primeiro elemento. O static é essencial: sem ele, o vetor seria destruído ao fim da função e p apontaria para memória inválida. Os valores se repetem entre r e p porque são o mesmo vetor, e não por causa do static, como diz o material.

Sugestão de Resolução
O que mudou em relação ao material
kg

Unidades

O original multiplicava o volume por 25 e comparava com kg: uma coluna de 1 m³ "pesaria" 25 kg. Usando 2.500 kg/m³, o resultado fica coerente com a tabela.

( )

Parâmetros

O original lia as medidas dentro da função. Recebendo-as como parâmetros, calcularPeso() fica reutilizável: serve para dados do teclado, de um arquivo ou de outro cálculo.

Escopo de Variáveis
Cada função, sua memória
1#include <stdio.h> 2int testar(){ 3 int x = 10; // x local de testar() 4 return x; 5} 6int main(){ 7 int x = 20; // x local de main() 8 printf("x em main() = %d\n", x); 9 printf("x em testar() = %d\n", testar()); 10 return 0; 11}

As duas variáveis se chamam x, mas não há conflito: cada uma é local à função em que foi declarada e tem seu próprio endereço. Uma variável local só existe dentro do corpo da sua função.

Escopo Global
Visíveis em todas as funções
1#include <stdio.h> 2float t1, t2; // variaveis globais 3float calcularMedia(){ 4 return (t1 + t2) / 2; 5} 6int main(){ 7 printf("Digite as duas temperaturas: "); 8 scanf("%f %f", &t1, &t2); 9 printf("Temperatura media = %.2f\n", calcularMedia()); 10 return 0; 11}
Saída no terminal
Digite as duas temperaturas: 18 25 Temperatura media = 21.50
+

Vantagem

Várias funções usam os mesmos dados sem precisar recebê-los.

−

Cuidado

Ficam na memória o tempo todo e qualquer função pode alterá-las, o que dificulta achar erros.

Uma variável global é declarada fora de qualquer função, por convenção logo após os #include. Prefira parâmetros: calcularMedia(t1, t2) deixa claro de onde vêm os dados.

Local x Global
Quando os nomes se repetem
1#include <stdio.h> 2int x = 10; // global 3int main(){ 4 int x = -1; // local: esconde a global 5 int b; 6 { 7 extern int x; // neste bloco, x e a global 8 b = x; 9 } 10 printf("x (local) = %d\n", x); 11 printf("b (x global) = %d\n", b); 12 return 0; 13}
Saída no terminal
x (local) = -1 b (x global) = 10

Se uma variável local tem o mesmo nome de uma global, a local prevalece dentro da função. Para alcançar a global, o bloco das linhas 6 a 9 declara extern int x: dentro dele, x volta a ser a variável global.

Passagem por Valor
A função recebe cópias

Na passagem por valor, a função cria variáveis locais para os parâmetros e copia nelas os argumentos. Ao terminar, essas cópias são liberadas. Alterar um parâmetro nunca altera a variável de quem chamou. Omitir um argumento esperado gera erro de compilação.

Exemplo de Passagem por Valor
Antes, durante e depois
1#include <stdio.h> 2void testar(int n1, int n2){ 3 n1 = -1; // altera apenas as copias 4 n2 = -2; 5 printf("Dentro de testar(): n1 = %d e n2 = %d\n", n1, n2); 6} 7int main(){ 8 int n1 = 10, n2 = 20; 9 printf("Antes da chamada: n1 = %d e n2 = %d\n", n1, n2); 10 testar(n1, n2); 11 printf("Depois da chamada: n1 = %d e n2 = %d\n", n1, n2); 12 return 0; 13}
Saída no terminal
Antes da chamada: n1 = 10 e n2 = 20 Dentro de testar(): n1 = -1 e n2 = -2 Depois da chamada: n1 = 10 e n2 = 20

Dentro de testar(), as cópias valem −1 e −2. De volta ao main(), n1 e n2 continuam 10 e 20. Como testar() não devolve nada, ela foi declarada void. O material usava int com um return 0 sem utilidade.

Situação-problema
O caixa da loja
Desafio da aula

Um amigo seu tem uma loja e precisa de um programa em C que calcule o preço total de uma compra a partir dos preços unitários e das quantidades de cada item. O cálculo deve ficar em uma função, com parâmetros passados por referência.

Uma função só devolve um valor com return. E se ela precisar alterar variáveis de quem chamou, ou receber vetores inteiros?

Ponteiros como Parâmetros
A função recebe endereços
Definição: parâmetros com *
void testar(int *n1, int *n2)
Chamada: argumentos com &
testar(&n1, &n2);

Não há cópia dos valores: a função recebe o endereço de cada variável e, com o operador *, lê e altera diretamente a memória de quem chamou.

Exemplo de Passagem por Referência
Agora a mudança permanece
1#include <stdio.h> 2void testar(int *n1, int *n2){ 3 *n1 = -1; // * acessa o conteudo do endereco 4 *n2 = -2; 5 printf("Dentro de testar(): n1 = %d e n2 = %d\n", *n1, *n2); 6} 7int main(){ 8 int n1 = 10, n2 = 20; 9 printf("Antes da chamada: n1 = %d e n2 = %d\n", n1, n2); 10 testar(&n1, &n2); // & envia os enderecos 11 printf("Depois da chamada: n1 = %d e n2 = %d\n", n1, n2); 12 return 0; 13}
Saída no terminal
Antes da chamada: n1 = 10 e n2 = 20 Dentro de testar(): n1 = -1 e n2 = -2 Depois da chamada: n1 = -1 e n2 = -2
Compare: a mesma função por valor
Antes da chamada: n1 = 10 e n2 = 20 Dentro de testar(): n1 = -1 e n2 = -2 Depois da chamada: n1 = 10 e n2 = 20

Dentro da função, *n1 = -1 grava no endereço recebido. Sem o *, estaríamos tentando alterar o próprio endereço.

Vantagens da referência

Economiza tempo e memória com dados grandes e permite que uma função produza vários resultados.

Passagem de Vetores
Vetores vão sempre por referência
1#include <stdio.h> 2void inserir(int a[]){ // recebe o endereco do vetor 3 for (int i = 0; i < 3; i++) { 4 printf("Digite o valor %d: ", i); 5 scanf("%d", &a[i]); 6 } 7} 8void imprimir(int b[]){ 9 for (int i = 0; i < 3; i++) 10 printf("numeros[%d] x 2 = %d\n", i, 2 * b[i]); 11} 12int main(){ 13 int numeros[3]; 14 inserir(numeros); // sem & e sem colchetes 15 imprimir(numeros); 16 return 0; 17}
Saída no terminal
Digite o valor 0: 3 Digite o valor 1: 5 Digite o valor 2: 7 numeros[0] x 2 = 6 numeros[1] x 2 = 10 numeros[2] x 2 = 14

Na chamada, o nome do vetor já é o endereço de numeros[0]: não precisa de &. O parâmetro pode ser escrito int a[] ou int *a. O nome do parâmetro (a, b) não precisa ser igual ao do argumento (numeros). Como a função não sabe o tamanho do vetor, é comum passá-lo também como parâmetro.

Passagem de Matrizes
Matrizes: informe as colunas
1#include <stdio.h> 2void dobrar(int mat[][3], int linhas){ 3 for (int i = 0; i < linhas; i++) 4 for (int j = 0; j < 3; j++) 5 mat[i][j] *= 2; // altera a matriz original 6} 7void imprimir(int mat[][3], int linhas){ 8 for (int i = 0; i < linhas; i++) { 9 for (int j = 0; j < 3; j++) 10 printf("%4d", mat[i][j]); 11 printf("\n"); 12 } 13} 14int main(){ 15 int m[2][3] = {{1, 2, 3}, {4, 5, 6}}; 16 dobrar(m, 2); 17 imprimir(m, 2); 18 return 0; 19}
Saída no terminal
2 4 6 8 10 12

Para calcular a posição de mat[i][j], o compilador precisa saber quantas colunas há em cada linha. Por isso o parâmetro é int mat[][3]: as linhas podem ficar em branco, mas as colunas são obrigatórias. Na chamada, basta o nome: dobrar(m, 2).

Passagem de Structs
Structs com ponteiro e ->
1#include <stdio.h> 2#include <string.h> 3struct Pessoa { 4 char nome[50]; 5 int idade; 6}; 7void modificarPessoa(struct Pessoa *p){ 8 p->idade = 30; // -> acessa o campo pelo ponteiro 9} 10int main(){ 11 struct Pessoa pessoa1; 12 strcpy(pessoa1.nome, "Joao"); 13 pessoa1.idade = 25; 14 printf("Antes: %s, %d anos\n", pessoa1.nome, pessoa1.idade); 15 modificarPessoa(&pessoa1); 16 printf("Depois: %s, %d anos\n", pessoa1.nome, pessoa1.idade); 17 return 0; 18}
Saída no terminal
Antes: Joao, 25 anos Depois: Joao, 30 anos

A função recebe struct Pessoa *p e acessa os campos com ->. Assim, altera a struct original e evita copiar todos os campos, o que faz diferença em estruturas grandes. O material usava strcpy sem incluir string.h.

Situação-problema
Raiz quadrada pelo método de Newton
Desafio da aula

A equipe de matemáticos pediu um programa que calcule a raiz quadrada de um número por aproximações sucessivas, usando recursividade. Cada aproximação é calculada a partir da anterior:

xₙ = (xₙ₋₁² + n) / (2 · xₙ₋₁)

Quais valores precisam ser informados? O que determina o fim do cálculo? O método aceita qualquer número?

Funções Recursivas
Uma função que chama a si mesma
<tipo> funcaoRecursiva(<parâmetros>){ if (<caso base>) return <valor conhecido>; // ... return ... funcaoRecursiva(<problema menor>); }
⏹

Caso base

O cenário mais simples, resolvido sem nova chamada. É obrigatório: sem ele, a função se chama para sempre.

⧉

Instâncias independentes

Cada chamada cria uma nova cópia das variáveis na memória, com endereços próprios.

!

Estouro de pilha

Chamadas demais esgotam a memória (stack overflow) e o programa é encerrado.

Como Funciona
5 + 4 + 3 + 2 + 1 + 0, recursivamente
1#include <stdio.h> 2int somar(int valor){ 3 if (valor <= 0) // caso base: criterio de parada 4 return 0; 5 return valor + somar(valor - 1); // chamada recursiva 6} 7int main(){ 8 int n; 9 printf("Digite um numero inteiro positivo: "); 10 scanf("%d", &n); 11 printf("Resultado da soma = %d\n", somar(n)); 12 return 0; 13}
Saída no terminal
Digite um numero inteiro positivo: 5 Resultado da soma = 15

somar(5) é 5 + somar(4); somar(4) é 4 + somar(3)… até somar(0), o caso base, que devolve 0 sem nova chamada. O material usava valor != 0: com um número negativo, valor nunca chega a zero e a pilha estoura. Com valor <= 0, a recursão sempre termina.

Na Memória
Desce chamando, sobe devolvendo
1

main() chama somar(2), que ainda não sabe o resultado: 2 + ?

2

somar(1) também espera: 1 + ?

3

somar(0) atinge o caso base e devolve 0.

4

Os resultados voltam: 1 + 0 = 1, depois 2 + 1 = 3, que chega ao main().

O Exemplo Clássico
n! = n × (n − 1)!
1#include <stdio.h> 2int fatorial(int valor){ 3 if (valor <= 1) // caso base: 0! = 1! = 1 4 return 1; 5 return valor * fatorial(valor - 1); 6} 7int main(){ 8 int n; 9 printf("Digite um numero inteiro positivo: "); 10 scanf("%d", &n); 11 printf("%d! = %d\n", n, fatorial(n)); 12 return 0; 13}
Saída no terminal
Digite um numero inteiro positivo: 5 5! = 120

O fatorial tem estrutura recursiva: 3! = 3 × 2!. O caso base é 0! = 1! = 1. Com int, o resultado só é correto até 12!. Acima disso, há estouro.

Cuidados
Recursão ou laço?
Recursiva
int somar(int valor){ if (valor <= 0) return 0; return valor + somar(valor - 1); }
Iterativa
int somar(int valor){ int resultado = 0; for (int i = 1; i <= valor; i++) resultado += i; return resultado; }
↻

Quando usar recursão

Quando cada instância do problema contém uma versão menor do mesmo problema: resolva direto se for pequena; senão, reduza e chame de novo.

⚖

Custo

Toda recursão pode virar laço. A recursiva costuma ser mais elegante; a iterativa, mais econômica em memória.

Atividade
Raiz quadrada recursiva
Desafio

Crie a função recursiva calcularRaiz(n, raizAnterior). Use a metade do número como chute inicial e pare quando a diferença entre duas aproximações for menor que 0,001.

1

Calcule a nova raiz com a fórmula, usando pow() de math.h.

2

Se fabs(raiz − raizAnterior) < 0,001, devolva a raiz: é o caso base.

Respondendo às perguntas do desafio
in

O que informar?

Só o número. O chute inicial (n/2) e a precisão (0,001) são definidos pelo programa.

⏹

O que encerra?

O caso base: duas aproximações seguidas diferem menos de 0,001. Para 144, foram 6 chamadas.

>0

Valor específico?

Sim: o número deve ser positivo. Com 0, o chute é 0 e há divisão por zero; o material não tratava isso e a recursão nunca terminava.

Também trocamos void main(), que não é padrão em C, por int main(), e float por double, já que pow, fabs e sqrt trabalham com double.

Funções e parâmetros
f()

Funções

Blocos com uma tarefa específica: tipo de retorno, nome, parâmetros e return. Modularizam e reaproveitam código.

void

Procedimentos

Funções void: executam uma tarefa e não devolvem valor.

{ }

Escopo

Locais existem só na função; globais, no programa todo. A local esconde a global de mesmo nome.

=

Por valor

A função recebe cópias. O original nunca muda.

&

Por referência

A função recebe endereços (*, &, ->). Vetores e matrizes vão sempre assim.

↻

Recursividade

A função chama a si mesma com um problema menor até o caso base.

1#include <stdio.h> 2struct Conta { 3 int numero; 4 char titular[50]; 5 float saldo; 6}; 7void realizarDeposito(struct Conta *conta, float valor){ 8 conta->saldo += valor; 9} 10int realizarSaque(struct Conta *conta, float valor){ 11 if (conta->saldo >= valor) { 12 conta->saldo -= valor; 13 return 1; // saque realizado 14 } 15 printf("Saldo insuficiente na conta %d.\n", conta->numero); 16 return 0; // saque recusado 17} 18int realizarTransferencia(struct Conta *origem, struct Conta *destino, 19 float valor){ 20 if (realizarSaque(origem, valor)) { 21 realizarDeposito(destino, valor); 22 return 1; 23 } 24 printf("Transferencia nao realizada.\n"); 25 return 0; 26}

Todas as funções recebem struct Conta *: alteram o saldo da conta original, e não de uma cópia. Se recebessem a struct por valor, o depósito "sumiria" ao final da função.

realizarSaque devolve 1 ou 0 para indicar sucesso. realizarTransferencia reaproveita as outras duas funções: só deposita no destino se o saque na origem der certo.
