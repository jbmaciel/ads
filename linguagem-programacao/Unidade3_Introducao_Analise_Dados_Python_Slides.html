Aplicação de Banco de
Dados com Python
Python simplifica a interação com sistemas de gerenciamento de banco de dados por meio de bibliotecas como o sqlite3.
SQL
Linguagem de Consulta Estruturada
A linguagem SQL desempenha papel fundamental na comunicação com bancos de dados relacionais. Suas instruções se agrupam em três categorias.
DDL

Definição de Dados

CREATE, ALTER e DROP criam, modificam e excluem tabelas e bancos de dados.

DML

Manipulação de Dados

SELECT, INSERT, UPDATE e DELETE recuperam, inserem, atualizam e excluem dados.

DCL

Controle de Dados

GRANT concede e REVOKE revoga privilégios de acesso aos dados.

O modelo CRUD (Create, Read, Update, Delete) resume as quatro operações fundamentais sobre dados em um banco.

Conexão com Banco de Dados
Do código ao SGBD
ODBC / JDBC

Acesso padronizado

Tecnologias que permitem que uma aplicação acesse diferentes SGBDs sem recompilar o código, por meio de um software chamado driver.

PEP 249

Python Database API

Estabelece que módulos de acesso a bancos de dados implementem um método connect(parameters...), facilitando a troca de banco sem alterar o código.

O SQLite é uma biblioteca de banco de dados SQL completa, compacta e confiável, que opera sem servidor separado: lê e escreve diretamente em um único arquivo no disco. Em Python, o módulo integrado sqlite3 permite interagir com ele.

Sua primeira tabela

CREATE TABLE é um comando DDL. Os passos para qualquer operação CRUD são sempre os mesmos: conectar, criar um cursor e executar o comando, confirmar com commit() e fechar cursor e conexão.

CRUD: Create e Read
Inserindo e consultando dados
# CREATE — inserir um novo produto conn = sqlite3.connect('exemplo.db') cursor = conn.cursor() novo_produto = ('Camiseta', 19.99, 50) inserir_produto = "INSERT INTO Produtos (nome, preco, estoque) VALUES (?, ?, ?)" cursor.execute(inserir_produto, novo_produto) conn.commit() conn.close()
# READ — listar todos os produtos conn = sqlite3.connect('exemplo.db') cursor = conn.cursor() cursor.execute("SELECT * FROM Produtos") produtos = cursor.fetchall() for produto in produtos: print(produto) conn.close()

O que é Pandas
DataFrames e Series
DF

DataFrame

Estrutura bidimensional, semelhante a uma tabela com linhas e colunas.

S

Estrutura unidimensional, semelhante a uma lista indexada.

Suporta CSV, Excel, SQL, JSON, HTML e muitos outros formatos.

O pandas é construído sobre o NumPy, simplifica o tratamento de dados ausentes e pode se integrar a bibliotecas de visualização como Matplotlib e Seaborn.

import sqlite3 # Passo 1: Conectar ao banco de dados SQLite (ou criá-lo) conn = sqlite3.connect("funcionarios.db") # Passo 2: Criar a tabela de funcionários cursor = conn.cursor() cursor.execute(''' CREATE TABLE IF NOT EXISTS funcionarios ( id INTEGER PRIMARY KEY, nome TEXT, cargo TEXT, salario REAL ) ''') # Passo 3: Inserir um novo funcionário novo_funcionario = (1, "João", "Analista", 5000.00) cursor.execute("INSERT INTO funcionarios VALUES (?, ?, ?, ?)", novo_funcionario) conn.commit() # Passo 4: Consultar e exibir funcionários cursor.execute("SELECT * FROM funcionarios") for funcionario in cursor.fetchall(): print(funcionario) # Passo 5: Atualizar informações de um funcionário atualizacao = ("João Silva", 5500.00, 1) cursor.execute("UPDATE funcionarios SET nome = ?, salario = ? WHERE id = ?", atualizacao) conn.commit() # Passo 6: Deletar um funcionário da tabela id_funcionario_para_deletar = 1 cursor.execute("DELETE FROM funcionarios WHERE id = ?", (id_funcionario_para_deletar,)) conn.commit() conn.close()
