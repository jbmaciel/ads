Estruturas Lógicas
Combinando condições
and

Operador "E"

Em (a and b), o resultado é Verdadeiro somente quando ambos os argumentos são verdadeiros.

or

Operador "OU"

Em (a or b), o resultado é Verdadeiro se pelo menos um dos argumentos for verdadeiro.

not

Operador "NÃO"

(not a) inverte o valor do argumento: transforma Verdadeiro em Falso, e vice-versa.

Os operadores booleanos são essenciais para criar decisões mais sofisticadas, permitindo que os programas lidem com uma variedade de situações e critérios lógicos.

Estruturas Condicionais
if, elif e else
O elif é uma abreviação de "else if" e permite avaliar múltiplas condições em sequência, do topo para baixo, até que uma seja verdadeira.
idade = 25 if idade < 18: print("Menor de idade") elif idade >= 18 and idade < 65: print("Adulto") else: print("Idoso")

Os comandos if e else funcionam como bifurcações em uma estrada: se a condição for verdadeira, o fluxo segue por um caminho; caso contrário, segue por outro. O elif permite verificar quantas condições forem necessárias antes do else final.

Estrutura for
Percorrendo uma sequência
O loop for é especialmente útil quando sabemos previamente quantas vezes queremos repetir uma ação ou quando temos uma coleção de itens a processar.
numeros = [1, 2, 3, 4, 5] for numero in numeros: print(numero) #a saída será: 1 2 3 4 5
Estrutura while
Repetindo enquanto uma condição é verdadeira
O while é ideal quando o número de repetições não é conhecido antecipadamente — a execução continua até que a condição especificada deixe de ser verdadeira.
numero = int(input()) while numero != 0: if numero % 2 == 0: print("par") else: print("ímpar") numero = int(input())

Esse exemplo permite que o programa solicite números repetidamente até que o número zero seja inserido, encerrando o loop.

Função range()
Três formas de criar sequências
1

Por quantidade

range(5) cria uma sequência de 0 a 4, com 5 iterações.

for x in range(5): print(x) → 0 1 2 3 4

2

Limites inicial e superior

range(2, 7) vai de 2 a 6 (o limite superior não é incluso).

for y in range(2, 7): print(y) → 2 3 4 5 6

3

Com incremento

range(1, 11, 2) começa em 1, vai até 10 e incrementa de 2 em 2.

for z in range(1, 11, 2): print(z) → 1 3 5 7 9

break e continue
Controlando o fluxo do loop
# break interrompe o loop for numero in range(1, 11): if numero % 2 == 0: print(f"Primeiro número par: {numero}") break #a saída será: Primeiro número par: 2
# continue pula para a próxima iteração for numero in range(1, 11): if numero == 5: continue print(numero) #a saída será: 1 2 3 4 6 7 8 9 10
Atividade
Classificando filmes do mês
Desafio

Crie um algoritmo capaz de percorrer cinco filmes e atribuir a cada um deles uma nota de 1 a 5, permitindo que o usuário encerre a classificação a qualquer momento digitando 0.

1

for

Percorra a lista de cinco filmes.

2

while True

Repita a pergunta até receber uma nota válida ou o pedido de parar.

3

break

Encerre o loop interno ao validar a nota ou ao receber "0".

Sugestão de Resolução
for aninhado com while True
filmes = ['Filme 1', 'Filme 2', 'Filme 3', 'Filme 4', 'Filme 5'] for filme in filmes: while True: classificacao = input(f"Classifique {filme} de 1 a 5 (ou 0 para parar): ") if classificacao == '0': print(f"{filme} interrompida.") break # encerra o loop interno com "break" classificacao = int(classificacao) if classificacao < 1 or classificacao > 5: print("Nota inválida, digite de 1 a 5.") else: print(f"{filme} com {classificacao} estrelas.") break # sai do loop interno

Utilizamos "while True" — técnica comum para criar loops em que a condição de parada pode variar ou não é conhecida, como neste caso, em que o usuário pode parar a qualquer momento.

Funções Built-in
Ferramentas prontas para uso
Python oferece um repertório de cerca de 70 funções built-in, pré-instaladas e incorporadas ao coração da linguagem, sem necessidade de instalação adicional.
print

Exibe um objeto no formato de texto.

int

Retorna um objeto inteiro a partir de um número ou string.

range

Cria um tipo de sequência imutável de números.

len

Calcula o comprimento de uma lista ou sequência.

# Cria uma lista de números numeros = [1, 2, 3, 4, 5] # Usa a função len() para calcular o comprimento da lista comprimento = len(numeros) print(f"O comprimento da lista é: {comprimento}") O comprimento da lista é: 5
Funções Definidas pelo Usuário
Com retorno e parâmetro
# Definindo uma função chamada "soma" def soma(a, b): resultado = a + b return resultado resultado_soma = soma(5, 3) print(f"A soma de 5 e 3 é: {resultado_soma}") A soma de 5 e 3 é: 8
# Definindo uma função chamada "e_par" def e_par(numero): if numero % 2 == 0: return True else: return False

Funções definidas por nós têm controle sobre o nome, os dados que recebem (parâmetros) e o resultado que produzem (retorno), permitindo personalizar soluções para demandas específicas.

Funções Lambda
Funções anônimas
Expressões lambda criam funções sem um nome definido com "def". São úteis quando você precisa de uma ação simples que será usada apenas uma vez.
soma = lambda a, b: a + b resultado = soma(3, 4) print(resultado) # Isso imprimirá 7 7

Não atribuímos um nome com "def", mas podemos usar a expressão lambda como qualquer outra função — ideal para tarefas pequenas e específicas.

Atividade
Upgrade na calculadora de médias
Desafio

Utilizando os conhecimentos desta aula, crie uma função para calcular a média de uma lista de notas, uma expressão lambda para arredondar o resultado e uma estrutura condicional para definir a situação do estudante.

1

def calcular_media

Some as notas com sum() e divida pelo total com len().

2

lambda

Arredonde a média com round(media, 2).

3

Situação

Compare a média arredondada com a nota mínima de aprovação.

Sugestão de Resolução
Função, lambda e condicional juntos
# Lista de notas dos estudantes notas = [7.5, 8.0, 6.5, 9.0, 7.0] # Função regular para calcular a média def calcular_media(notas): total = sum(notas) media = total / len(notas) return media # Função lambda para arredondar a média para duas casas decimais arredondar_media = lambda media: round(media, 2) media = calcular_media(notas) media_arredondada = arredondar_media(media) # Verificar se os estudantes foram aprovados situacao = "Aprovado" if media_arredondada >= 7 else "Reprovado" print(f"Notas: {notas}") print(f"Média: {media_arredondada}") print(f"Situação: {situacao}")
